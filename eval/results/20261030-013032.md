**Agent answer** (high): AI support agent memory approaches are generally divided into short-term (working) memory and long-term memory systems. Long-term memory is further subdivided into episodic memory (tracking specific past interactions, user preferences, and previous support tickets) and semantic or organizational memory (storing general product documentation, policies, and facts). *Confidence reason:* Multiple independent sources consistently define and contrast short-term memory, long-term memory, episodic memory, and semantic memory in AI agents, detailing their underlying storage mechanisms and operational roles.
